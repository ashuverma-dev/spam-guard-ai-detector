# Spam Guard AI Detector

A privacy-friendly spam message detector that runs entirely in the browser.
Paste an SMS, email, or notification to receive an instant prediction and
confidence score.

## Features

- Browser-only spam analysis
- No backend or external API
- No login or personal data storage
- Example messages for quick testing
- Responsive interface for desktop and mobile
- Ready for static hosting on Netlify

## Live Demo

[spamdetectorr.netlify.app](https://spamdetectorr.netlify.app/)

## Deployment

This repository already contains the production-ready static files.

1. Sign in to Netlify.
2. Open **Deploy manually**.
3. Upload this repository folder.
4. Wait for Netlify to publish the site.

No build command, backend, environment variable, or API key is required.

## Privacy

Message analysis runs locally in the visitor's browser. Messages are not sent
to a server.
